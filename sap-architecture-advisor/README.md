# SAP Architecture Advisor

SAP Architecture Advisor is an ICA Edge skill that helps solution architects design and evaluate SAP-centric architectures.

## Capabilities

- Search SAP documentation
- Search Microsoft documentation
- Search Databricks documentation
- Recommend architecture patterns
- Compare architecture options
- Generate Mermaid diagrams
- Provide SAP best-practice guidance

## Supported Technologies

- SAP S/4HANA
- SAP Datasphere
- SAP Business Data Cloud (BDC)
- SAP BW/4HANA
- SAP Analytics Cloud (SAC)
- SAP HANA Cloud
- SAP Joule
- SAP Knowledge Graph
- Azure Databricks
- Microsoft Fabric
- Azure AI Foundry
- Power BI
